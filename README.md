## 按领域浏览

- **数论**（最大类）：素数分布、加法数论、丢番图方程、L 函数、完全数 —— 黎曼、哥德巴赫、孪生素数、abc、华林…
- **拓扑**：庞加莱、几何化、光滑庞加莱
- **几何**：开普勒、高斯-邦内、欧拉多面体、三大尺规难题
- **代数几何**：霍奇、BSD、莫德尔
- **理论计算机**：P vs NP、停机问题、AKS
- **逻辑 / 集合论**：哥德尔不完备、连续统假设
- **数学物理 / 偏微分**：杨-米尔斯、纳维-斯托克斯
